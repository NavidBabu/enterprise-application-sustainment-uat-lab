# Enterprise Application Sustainment & UAT Lab

A simulated business/technology sustainment project focused on the workflow used to support enterprise applications after deployment.

> All requirements, users, issues, test cases, and operational records are simulated. No confidential employer or production data is used.

## What the project demonstrates

- Business requirements documentation
- Acceptance criteria and traceability
- User acceptance testing (UAT)
- Defect / issue investigation
- Reporting and data analysis
- Change / enhancement coordination
- End-user documentation and job aids
- Continuous-improvement workflow
- Cross-functional business + technology communication

## Files

- `Enterprise_Application_Sustainment_UAT_Lab.xlsx`
- `issue_analysis.py`
- `PROCESS_WORKFLOW.md`

## Interview explanation

I built this project to practice the sustainment lifecycle of an enterprise application. I created a business requirements register, linked each requirement to UAT test cases, logged simulated defects, tracked changes, and created end-user documentation. I also built a dashboard to summarize UAT pass rate, open issues, issue severity, change readiness, and documentation status.

The project helped me connect software and technical troubleshooting experience with business analysis, testing, reporting, process documentation, and user support.
