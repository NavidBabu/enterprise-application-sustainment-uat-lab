# Enterprise Application Sustainment Workflow

1. **Capture request or issue**
   - business need
   - user problem
   - improvement idea

2. **Analyze and document**
   - business requirement
   - impact
   - priority
   - acceptance criteria
   - owner

3. **Test and validate**
   - UAT scenario
   - expected result
   - actual result
   - evidence
   - defect if failed

4. **Coordinate change**
   - implementation plan
   - user communication
   - validation
   - rollback approach

5. **Sustain and improve**
   - investigate issues
   - measure results
   - update documentation
   - capture lessons learned
   - identify continuous improvements

## Traceability rule

Each approved requirement should link to a UAT case and, when implemented, to a change record. Failed tests should create an issue that is investigated, resolved, re-tested, and documented before closure.
